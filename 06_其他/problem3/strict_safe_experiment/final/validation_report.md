# 第三问严格安全时刻实验

- 4 h 后环境固定为 50 °C、0.05 kg/kg；
- 主网格 N=2560，空间步长 7.8125000000e-06 m；
- 主时间步长 0.5 s；
- 求解器事件阈值：0.14994 kg/kg；
- 合计场值误差安全上界：3.81366241e-06 kg/kg；
- 含误差的含水率上界：0.149943813662 kg/kg < 0.14995；
- 事件时刻：207106.469099 s；
- 连续认证安全时刻：207106.483274 s；
- 整分钟工程安全时刻：207120 s = 57.533333333 h；
- 烘干时刻合计误差安全上界：0.014174 s；
- Excel：A1:V3453，ZIP=ok。

认证采用 `事件阈值 + 场值误差上界 < 0.14995`，并将事件时刻加上
烘干时刻误差上界后再向上取整到整分钟。
