# A 题提交代码与结果文件

本目录汇总 A 题第一至第四问的正式 Python 求解代码、绘图代码及最终 Excel 结果。提交内容按 `solve/`、`visualize/` 和 `result/` 三类平铺存放，三个目录内均无子文件夹。

## 最终结果文件

| 文件 | 对应问题 | 结果版本 |
|---|---|---|
| `result/result1.xlsx` | 第一问 | 1520 个径向区间、时间步长 0.03125 s 的高精度结果 |
| `result/result2.xlsx` | 第二问 | 760 个径向区间、自适应隐式 BDF 的高精度结果 |
| `result/result3.xlsx` | 第三问 | 4 h 后环境固定为 50 °C、0.05 kg/kg，$N=5120$、时间步长 0.25 s |
| `result/result4.xlsx` | 第四问 | 同一固定环境条件下，$N=12160$、相对容差 $10^{-12}$ 的高精度自适应隐式 BDF |

第三问超精细计算的连续临界时刻为 57.472300886994 h；第四问连续临界时刻为 51.090576239622 h，论文按题意保留四位小数后报告为 51.0906 h。51.133333333333 h 仅为使中心含水率在四位小数下明确显示为 0.1499 的保守操作时长，不作为第四问的模型答案。

题目明确要求在论文正文展示的表 1—表 6 已汇总于 `A题论文必备实验表格汇总.md`。

第四问采用收缩区域上的移动边界模型。当某个固定物理半径已经位于药材外部时，`result4.xlsx` 中相应单元格按题意留空；这些空白均为每行有效径向数据之后的连续尾部空白，最后一列“药材表面”始终保存移动表面的计算值。

## 文件分类

`solve/` 中每问仅保留一个能够生成正式结果的源文件：

- `solve_1.py`：第一问固定半径热湿模型；
- `solve_2.py`：第二问变物性热湿耦合模型；
- `solve_3.py`：第三问固定环境超精细计算；
- `solve_4.py`：第四问收缩模型超精细计算。

`visualize/` 中的绘图入口按“问题号-图序号”命名，并统一使用 `visualize_` 前缀：

- `visualize_1-1.py`：附件 1 全过程环境曲线；
- `visualize_1-2.py`：附件 1 前 30 min 局部环境曲线；
- `visualize_3-1.py`：第三问水分浓度曲面、干燥阈值面及深红虚线交界；
- `visualize_4-1.py`：附件 2 外半径变化图；
- `visualize_4-2.py`：第四问非仿射收缩诊断图；
- `visualize_4-3.py`：预测半径与附件 2 数据对比图；
- `visualize_4_2_model.py`、`visualize_4_3_model.py`：仅供后两张图复算绘图数据的内部支持模块。

## 环境与运行说明

建议使用 Python 3.11 或更新版本，并在本目录执行：

```bash
python -m pip install -r requirements.txt
```

主求解器需要题目原始的 `附件1.xlsx`、`附件2.xlsx` 和附件 3 中相应的空白结果模板。整理后的文件位于：

```text
../02_题目与附件/附件/附件1.xlsx
../02_题目与附件/附件/附件2.xlsx
../02_题目与附件/附件/附件3/result1.xlsx ... result4.xlsx
```

也可通过各脚本的 `--input`、`--environment`、`--radius`、`--template` 和 `--outdir` 等参数显式指定文件位置。四个求解文件默认将结果写入 `result/`；该目录已经包含正式提交结果，复算前建议先备份。

第三问三维图可直接由根目录的最终结果复绘：

```bash
python visualize/visualize_3-1.py
```

运行轻量级语法检查：

```bash
python -m compileall -q solve visualize
```

四个正式结果文件的 SHA-256 校验值见 `SHA256SUMS.txt`。
