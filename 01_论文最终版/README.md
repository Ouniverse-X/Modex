# 最终论文说明

- `A题论文最终版.pdf`：当前最新版成稿，原文件为 `new(15).pdf`。
- `final.tex`：整理后的最新版 LaTeX 源文件。
- `附录代码图片/`：附录代码的 40 张裁边图片。
- `figures/`：当前工作区中能够确认的正式配图。
- `cumcmthesis.cls`：论文模板类文件。
- `graphics_compat.tex`：缺图兼容文件；源图不存在时以明确占位框代替，使文档仍可编译。

在本目录中使用 XeLaTeX 编译：

```bash
latexmk -xelatex -interaction=nonstopmode -halt-on-error final.tex
```

部分正文图片的独立源文件在原工程中已经缺失，因此 `A题论文最终版.pdf` 是排版与图片内容的权威成稿。缺图兼容文件只用于保证整理后的源文件可复核，不会改变已生成的最终 PDF。

当前缺少的独立图源包括：问题二正文流程图与结果图、问题三流程图/折线图/等值线图/圆柱图、问题四流程图与结果图，以及严格守恒对照模型图。它们已经嵌入最终 PDF，但无法从原工程中确认对应的最新版独立源文件。
